# UI / 페이지 흐름

## 공개 페이지

### `/` (메인) — Phase 2 업데이트
- **상단**: 공임비 안내 배너 ("공임비: 기본 1만원 / 작업 1회")
- **보유 스트링 섹션** (신규): 카드 5~6개 + "전체 보기" 링크 → `/strings`
  - 카드 기본 표시: 브랜드, 이름, 게이지, 카테고리, 색상, **비용**
  - "상세 ▼" 버튼 → 카드 아래에 펼쳐짐 (JS 토글): 형태, 강성(RA), 텐션 로스, 스핀 잠재력
- **검색/필터 폼**: 고객명/라켓/스트링/메모 통합 텍스트, 스트링 종류, 날짜 범위, 텐션 범위
- **테이블**: 작업 이력 (라켓 헤드사이즈·패턴, 텐션, 컷 길이, 비용, 메모)

### `/strings` (스트링 마스터 목록) — Phase 2 신규
- 헤더: "스트링 목록" + "← 작업 이력"
- 검색 입력 (브랜드/이름/카테고리/게이지), 카테고리 필터
- 카드 그리드 (반응형)
- 각 카드: 위 `/` 메인 카드와 동일 (기본 + 상세 토글)

### `/strings/:id` — Phase 2 (선택)
- 단일 스트링의 전체 정보
- 관리자 평가 데이터(강성/텐션로스/스핀)도 표시 (공개 페이지이므로 단일 페이지에서 한 번에 보이게 할지, 일반 카드의 상세 토글로 충분할지는 결정 후)

### `/apply` (신청 폼) — Phase 5-24 신규
- `?type=job`: 스트링 선택(품절 비활성) + 메인/크로스 텐션 + 이름 + 라켓 + 희망날짜 + 메모
- `?type=purchase`: 스트링 선택(품절 포함) 또는 직접 입력 + 이름 + 메모
- `?string={id}`로 카드에서 preselect. 접수 후 확인 페이지

## 관리자 페이지

### `/admin/login`
- 비밀번호 입력 → POST `/api/auth/login`

### `/admin` (대시보드)
- 최근 작업 이력 (최대 100건)
- 라켓 컬럼 아래에 헤드사이즈·패턴
- 텐션, 컷 길이 (main/cross), 비용 표시
- 각 행에 수정/삭제
- 신규 신청 N건 뱃지 (Phase 5-24, 0건이면 숨김)

### `/admin/requests` (신청 관리) — Phase 5-24 신규
- 신청 목록 (유형/상태 뱃지, 상태 필터)
- 작업 신청 + 신규 상태면 "이력으로 등록" → `/admin/new?request={id}` 프리필 (스트링·텐션·날짜·메모, 고객/라켓 직접 선택) → 등록 시 신청 완료 처리
- 완료/반려/삭제 버튼

### `/admin/customers`
- 고객 목록 + 라켓 수
- 신규 고객 등록 폼

### `/admin/customers/:id`
- 고객 상세
- 신규 라켓 등록 폼 (모델명, 별칭, 헤드사이즈, 스트링 패턴)
- 라켓 테이블: ID, 모델명, 별칭, 헤드사이즈, 패턴, **관리** (수정/삭제)

### `/admin/new` (작업 등록)
- 고객 select + 라켓 select (datalist 동적 갱신)
- 신규 라켓 인라인 등록 (모델/별칭/헤드/패턴)
- 스트링 종류: **input + datalist 자동완성** (Phase 2)
  - 옆에 `<datalist>`로 마스터 스트링 자동완성
  - 선택 시 hidden `string_id` 세팅
  - 마스터에 없는 이름 입력 시 string_id 비움 (string_type만 저장)
- 텐션 (main/cross), 컷 길이 (main/cross, 라켓 길이), 비용, 작업일, 메모

### `/admin/edit/:id`
- 작업 수정 폼 (모든 필드 prefill)

### `/admin/rackets/:id/edit`
- 라켓 정보 수정 (모델명/별칭/헤드사이즈/패턴)

### `/admin/strings` (Phase 2 신규)
- 스트링 마스터 관리
- 검색 + 카테고리 필터
- 테이블: 브랜드, 이름, 카테고리, 형태, 게이지, 색상, 강성, 텐션 로스, 스핀 잠재력, 비용, 공임비, **관리**
- "＋ 새 스트링" 버튼 → `/admin/strings/new`

### `/admin/strings/new`, `/admin/strings/:id/edit` (Phase 2)
- 스트링 등록/수정 폼
- 전체 필드 입력
- 카테고리/형태/색상은 `<select>`로 선택

## 디자인 규칙

- **Tailwind CSS** (CDN), `<script src="https://cdn.tailwindcss.com">`
- 모든 페이지: `Layout` 컴포넌트 (`src/views/layout.tsx`) 사용
- 한글 UI, escape 처리 (`escapeHtml`)
- Hono JSX에서 `<script>` 자식 escape 문제 → 반드시 `dangerouslySetInnerHTML={{ __html: ... }}` 사용
- Drizzle select 결과를 prop으로 넘길 때 plain object로 명시적 변환
